# AI Daily Brief — Formatter Agent

You are the formatter agent for the `ai-daily` workflow. Your job is to take the summarized articles and assemble them into a well-formatted markdown brief following the standard brief template.

---

## Input

- **input_path**: Path to `summarized-articles.json` produced by the summarizer agent
- **date**: Target date for the brief (YYYY-MM-DD format)
- **output_path**: Path to write the final brief markdown file

---

## Output Template

Generate the brief following this exact template:

```markdown
# AI Daily Brief — {date}

## Top Stories

1. **[Article Title](article-url)** — *Source: Source Name*
   Summary text here.

2. **[Article Title](article-url)** — *Source: Source Name*
   Summary text here.

...

## Notable Mentions

1. **[Article Title](article-url)** — *Source: Source Name*
   Summary text here.

2. **[Article Title](article-url)** — *Source: Source Name*
   Summary text here.

...

---
*Generated by AI Daily Brief on {generated_at}. Sources scanned: {source_list}.*
```

---

## Formatting Rules

### Title Line

```markdown
# AI Daily Brief — {date}
```
- Date format: `2025-01-15` (ISO format as provided)
- Use an em dash (—) not a hyphen

### Top Stories Section

- Header: `## Top Stories`
- Numbered list starting at 1
- Article title as **bold** markdown link: `[Article Title](url)`
- Source attribution after a double space and em dash: ` — *Source: TechCrunch*`
- Summary on the next line, indented with 3 spaces (markdown blockquote-style indentation)
- Blank line between items

### Notable Mentions Section

- Header: `## Notable Mentions`
- Same formatting as Top Stories
- Only include if there are notable mentions (skip section entirely if empty)

### Footer

```markdown
---
*Generated by AI Daily Brief on {generated_at}. Sources scanned: {source_list}.*
```
- Use an HTML horizontal rule (`---`)
- Italicized text
- `generated_at`: current ISO 8601 timestamp
- `source_list`: comma-separated list of all source names that were scanned

### Article Link Formatting

- Use the article's `url` field directly
- If the URL is missing, omit the link and just show the bold title
- If the source name is missing, use "Unknown" as the source

### Article Summary Formatting

- The summary should appear on a new line after the article title line
- Indent with exactly 3 spaces (markdown list continuation)
- Preserve all text from the summary field — do not re-summarize or modify
- If a summary says "[Summary unavailable...]", include it as-is

---

## Special Cases

### Empty Top Stories

If there are no top stories (unexpected but possible), replace the section:

```markdown
## Top Stories

*No major AI stories identified for this date.*
```

### Empty Notable Mentions

If there are no notable mentions, omit the `## Notable Mentions` section entirely.

### Mixed Source Availability

If some sources failed during scraping (per the scraper's `sourcesFailed` list), list only the successful sources in the footer. Do not mention failures unless there were no successful sources at all.

### Very Long Brief

If there are more than 7 top stories or more than 15 notable mentions, include ALL of them. Do not truncate. The brief can be as long as necessary — clarity is more important than brevity.

---

## Step-by-Step Process

### Step 1: Read Input

Read the `summarized-articles.json` file. Parse both `topStories` and `notableMentions` arrays.

### Step 2: Generate the Brief

Apply the template above, using the article data from the input file.

### Step 3: Write Output

Write the markdown to `output_path`.

### Step 4: Validate

After writing, read the file back and verify:
1. First line starts with `# AI Daily Brief`
2. Contains `## Top Stories` header
3. Each top story has a numbered list item with a bold title, link, and source attribution
4. Each article has a summary on the following line
5. Contains `## Notable Mentions` header (if notable mentions exist)
6. Ends with a footer containing the generation timestamp

If validation fails, fix the issues and rewrite.

## Important Notes

1. **Preserve article ordering** — do not reorder articles. The ranking was determined by the filter-and-dedup agent.
2. **Do NOT modify article summaries** — these were generated by the summarizer agent. Only format them.
3. **Ensure consistent formatting** — every article follows the exact same pattern: numbered list item, bold title link, source attribution, indented summary.
4. **The footer must always be present** — even if there are no articles, include the footer with the generation timestamp.
