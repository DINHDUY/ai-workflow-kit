OpenAI released a suite of **three specialized real-time voice models** designed as distinct orchestration primitives:

- **GPT-Realtime-2** — The first voice model with "GPT-5 class reasoning," capable of handling complex, multi-turn requests
- **GPT-Realtime-Translate** — Supports 70+ input languages with real-time output to 13 languages
